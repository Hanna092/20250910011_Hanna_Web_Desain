1. Perbedaan var, let, dan const

  • var memakai function scope. Variabel var di dalam blok { } tetap bisa diakses dari luar blok.
  • let memakai block scope. Variabel hanya bisa diakses di dalam blok tempat ia dibuat, dan nilainya boleh diubah.
  • const juga block scope, tetapi nilainya tidak bisa diubah.

Contoh kode (hasilnya ada di Console, tekan F12):

if (true) {
  var a = 1;
  let b = 2;
  const c = 3;
}
console.log(a); // 1
console.log(b); // ReferenceError
console.log(c); // ReferenceError

const d = 10;
d = 20; // TypeError

3. Global scope dan local scope

  • Global scope: variabel dideklarasikan di luar fungsi, sehingga bisa diakses dari mana saja.
  • Local scope: variabel dideklarasikan di dalam fungsi, sehingga hanya bisa diakses di dalamnya.
let global = "Saya variabel global";

function contoh() {
  let lokal = "Saya variabel lokal";
  console.log(global); // bisa diakses
  console.log(lokal);  // bisa diakses
}

contoh();
console.log(global); // bisa diakses
console.log(lokal);  // ReferenceError

Variabel lokal tidak bisa diakses dari luar karena hanya hidup di dalam fungsi contoh().
