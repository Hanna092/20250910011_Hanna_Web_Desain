1. Apa itu JavaScript dan untuk apa biasanya digunakan?

JavaScript adalah bahasa pemrograman yang berjalan di browser (dan di server lewat Node.js). Bersama HTML (struktur) dan CSS (tampilan), JavaScript membuat halaman web menjadi interaktif dan dinamis.

Kegunaan umumnya:

  • Mengubah isi dan gaya elemen HTML secara dinamis (innerHTML, style)
  • Menangani peristiwa seperti klik, input, dan hover (addEventListener)
  • Validasi formulir sebelum dikirim
  • Membuat fitur seperti pencarian, filter, dan slider
  • Mengambil data dari server tanpa memuat ulang halaman (fetch)
  • Membuat aplikasi web dan game sederhana

3. Kondisi if, else if, dan else

Kondisi dipakai untuk menjalankan kode tertentu hanya jika syarat terpenuhi. Pertama if diperiksa. Jika salah, lanjut ke else if. Jika semua salah, else dijalankan. 

let nilai = 80;

if (nilai >= 85) {
  console.log("Nilai A");
} else if (nilai >= 70) {
  console.log("Nilai B");
} else {
  console.log("Nilai C");
}
